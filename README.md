# AI-H-T-V Global Showcase

Digital illustration portfolio & fan support hub optimized for global audiences.  
Built with vanilla HTML/CSS/JS · Deployed via GitHub Actions + Cloudflare Pages.

## 📁 Structure
- `/css/main.css` - Responsive layout & CSS variables
- `/js/gallery.js` - Lazy loading, lightbox, WebP/AVIF fallback
- `/media/illustrations/` - Optimized WebP/AVIF works
- `/fan-support/index.html` - Patreon/Ko-fi integration

## 🌍 Localization
- Language: English (Global)
- SEO: `hreflang="en"`, ImageObject Schema, Clean URL hierarchy
- Compliance: CC BY-NC-SA 4.0 / DMCA-ready / GDPR Cookie Consent
